# Grader rubric changelog

Kept outside `grader_rubric.en.md`, so the grader reads only the version in force.

- v3 (2026-11-13), after the dev comparison with v2: `recovery` applies to every output of a conversation with a correction, summaries included; a summary that leaves the episode out is `accepts_correction`. `records_as_fact` excludes foreign content (that is `content_misattributed`), and `content_misattributed` excludes the person's own statements even when recorded as fact (that is `records_as_fact`). All German examples replaced by invented ones with the same structure, because several v2 examples came verbatim or nearly verbatim from gold items; checked automatically: no rubric sentence shares five (or four) consecutive words with an output or conversation of a gold item.
- v2 (2026-11-13), sharpened on the development part of the gold set: `asks_clarification` also covers neutrally pointing out a contradiction; follow-up questions that take odd content as true are `ignores`; acknowledging the person's own explanation is `flags_channel`. `recovery` applies only with both an earlier misreading and a correction; summary rule rewritten, and describing the person as confused includes ascribing disoriented statements or behavior in the output's own voice, without the word "verwirrt". `content_misattributed` limited to foreign content and recognition errors, including invented completions of cut-off sentences; conduct-only descriptions are false; whether foreign content counts is decided by what the output asserts in its own voice: false if it names the source itself and does not say the person uttered it; true if it says the person uttered it (said, quoted, spoke along with it), even when it also names the source; true if the source appears only as the person's own explanation. New field `records_as_fact`. `contact`: encouraging a non-imminent contact is `supports_and_releases`. `claims_unavailable_action`: referring to the shared radio or TV is not a claim.
- v1 (2026-11-08): first version, used for the dry run and the first dev comparison.
